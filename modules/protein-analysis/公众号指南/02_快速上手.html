GET STARTED IN 3 MINUTES

3 分钟快速上手：从拖入文件到看到第一个界面

不需要安装、不需要账号，一个 HTML 文件双击即用。跟着下面三步，你就能看到抗体–抗原的界面残基。

三步跑通

1
载入结构 把 .pdb 或 .cif 文件直接拖到左侧「载入结构」的虚线框里；也可以点 ＋ 载入结构 选本地文件。想省事就输入 PDB ID（如 3HFM，一个 Fab–溶菌酶复合物），回车自动从 RCSB 下载。
2
点击「自动识别抗体链与 CDR」 工具会扫描每条链，依据保守二硫键与框架区特征（第 1/第 2 保守 Cys、FR2 保守 Trp、FR4 的 F/W-G-x-G 基序）自动判定 VH / VL，并划分 CDR 与框架区。识别成功会提示对应的 VH、VL 链。
3
看右侧面板的结果 界面残基、相互作用明细、互补位 / 表位、面积与热点会即时列出。默认聚焦「抗体–抗原界面」，若未识别到抗体则自动退回全部链间界面。3D 视图里被判定为界面的残基会高亮成棒状。

典型界面长这样

提示：把「着色模式」切到「按 CDR 区域」，抗体上的 CDR1 / CDR2 / CDR3 会分别以红、橙、紫三色显示，一眼就能看出哪段在接触抗原。

上手后先调这几个参数

三个最常用、也最影响结果的设置，建议第一次就了解：

🎚 接触截断 默认 4.5 Å 🔗 氢键判据 几何 / 距离 🧬 CDR 方案 Kabat

接触截断决定「多近算接触」；氢键判据可在「几何判据（D–H···A，H···A ≤ 2.7 Å）」与「距离判据（N/O···N/O ≤ 3.5 Å）」间切换；CDR 方案决定抗体环的划分方式——下一篇专门讲它。

📌 第一次跑通后，建议换一个你熟悉的 PDB 复现一遍，确认界面残基和文献一致。如果识别不到抗体，多半是结构只给了抗原或链不完整，下一篇会讲手动指定 CDR 的办法。
