# 10 · 模板元数据规范

> 定义「参考结构模板」的文件格式与字段约束。未满足本规范的模板不入库。
> 对应能力①设计见 `01_方案/03_模块设计_参考结构模板.md`。

## 1. 文件格式

- 每个模板一个目录：`NN_类型_名称/模板.md`。
- 模板正文使用 Markdown 层级（`#`/`##`/`###`）表达章节树。
- 每节下方用引用块 `> ` 写「写作指引」，用 `> 标签:` 写建议检索标签。

## 2. 模板头（YAML Front Matter，必填）

```yaml
---
id: tpl_投标方案_标准结构
type: 投标方案
name: 通用信息化项目投标方案
scenario: 政企信息化采购
version: 1.0.0
author: 知识管理员
tags: [信息化, 政府采购]
---
```

## 3. 章节字段约定

每个章节节点建议包含：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| title | 章节标题 | 项目理解 |
| level | 层级（1/2/3） | 1 |
| required | 是否必填 | true |
| placeholders | 需填写的占位符 | [项目名称, 采购人] |
| guidance | 写作指引（写入 `> ` 引用） | 说明对需求的理解… |
| source_tags | 建议检索的知识标签 | [案例, 需求] |

## 4. 章节书写示例

```markdown
## 项目理解 {#s1}

> guidance: 说明对采购需求的理解，引用类似案例与痛点。
> required: true
> placeholders: [项目名称, 采购人]
> source_tags: [需求分析, 历史案例]
```

## 5. 校验规则

- `id` 全局唯一；`type` 取自受控类型表（投标方案/技术方案/实施方案/…）。
- 章节 `title` 在本模板内不重复；`level` 连续不跳级。
- `source_tags` 必须能在 `04_知识库/02_分面与标签体系.md` 中找到或合理扩展。
- 版本号遵循语义化 `MAJOR.MINOR.PATCH`。
