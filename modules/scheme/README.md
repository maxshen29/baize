# Baize 方案撰写平台

> 一个面向「方案/标书/技术建议书」撰写的可复用、可检索、可按需生成的平台。
> 当前阶段：**已完成框架体系与方案/设计文档（调研 + 规划），技术栈已锁定 Vue3 + FastAPI + PostgreSQL(pgvector)，尚未进入开发。**

---

## 一、平台定位

Baize 方案撰写平台用于把「写一份方案」从纯手工劳动，变成 **模板牵引 + 知识沉淀 + 按需生成** 的半自动化过程。它借鉴了开源项目 [OpenBidKit_Yibiao（易标投标工具箱）](https://github.com/FB208/OpenBidKit_Yibiao) 的成熟思路（本地工作区、知识库复用、模板抽取、AI 生成、废标/查重检查），但将其抽象为**通用的方案撰写平台**，不局限于招投标场景。

平台依次提供四种核心能力：

| 序号 | 能力 | 说明 | 对应目录 |
| --- | --- | --- | --- |
| 1 | 可复用参考结构模板 | 沉淀各类方案的「骨架」，定义章节结构与每节写作指引 | `02_模板` |
| 2 | 导入并管理参考文档 | 把企业资料、历史方案、规范标准解析入库并持续管理 | `03_参考文档` |
| 3 | 构建可检索知识库 | 从参考文档/人工条目中切片建索引，支持语义+关键词检索 | `04_知识库` |
| 4 | 基于知识库按需撰写 | 依模板与知识库，按章节/按需生成方案内容，可溯源、可编辑 | `05_代码`（引擎）+ `01_方案/06_模块设计_按需撰写.md` |

## 三、命名与编号约定

- **目录**使用两位数字序号前缀：`00_`~`05_`，保证按序排列与「生成顺序明确」。
- **文档**使用 `NN_主题.md`；子模块用 `NN_模块设计_能力名.md` 明确归属。
- **模板/知识条目**使用「类型_名称」语义化命名，配套元数据文件（见 `02_模板/10_模板元数据规范.md`）。
- 所有内容优先使用 Markdown，便于检索、版本管理与后续渲染为 Word/网页。

## 五、白泽平台模块注册信息（迁移自 `E:/project/Baize/方案系统`）

本模块已按 **白泽平台模块管理体系**（`docs/MODULE_SPEC.md`）注册，注册元数据见同目录 `module.yaml`：

| 项 | 值 |
|----|----|
| code | `scheme` |
| name | 方案系统 |
| version | 1.0.0 |
| entry | `/modules/scheme`（前端 `ModuleHost` 以 iframe 加载本目录 `index.html`） |
| api_prefix | `/api/v1/modules/scheme` |
| status | enabled |
| dependencies | `data-analytics` (^1.0.0) |
| 声明权限 | `scheme:plan:read` / `scheme:plan:write` / `scheme:template:read` / `scheme:knowledge:read` |

**接入步骤**：① 平台「模块管理」提交 `module.yaml` 注册（或扫描 `modules/` 自动登记）；② 将 `module.yaml` 中声明的权限码分配至角色；③ 在「模块配置」设置 `llm_model`、`max_tokens` 等运行参数；④ 前端菜单出现「方案系统」，经 `ModuleHost` 加载本模块。

**说明**：`05_代码/` 内含既有 FastAPI 后端与 Vue3 前端，可作为本模块的路由包与静态资源二次接入平台；其自有表结构见 `05_代码/db/schema.sql`（建议加 `scheme_` 前缀隔离平台表）。
