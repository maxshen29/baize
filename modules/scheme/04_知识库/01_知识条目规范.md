# 01 · 知识条目规范

> 定义知识库最小可检索单元「知识条目」的格式与字段。对应设计见 `01_方案/05_模块设计_知识库.md`。

## 1. 文件格式

- 每个条目一个文件：`04_知识库/知识条目/KE_<YYYYMMDD>_<主题简称>.md`。
- 必备 YAML Front Matter（见下），正文为条目内容。

## 2. 字段定义

```yaml
---
id: KE_20260918_资质          # 唯一
title: 公司具备ISO9001认证
source_doc_id: doc_0001       # 溯源到参考文档
chunk_index: 12               # 文档内切片位置
keywords: [ISO9001, 认证, 资质]
facets:
  domain: 资质                # 领域分面
  applicable_template: [投标方案, 技术方案]   # 适用模板（多对多）
  source_type: 资质文件       # 来源类型分面
confidence: 0.95              # 人工条目可标注
status: active | merged | deprecated
embedding: <由系统生成，不入文件>
created_at: 2026-09-18
---
正文：公司持有 ISO9001:2015 质量管理体系认证，证书编号……（一段完整语义）
```

## 3. 编写规则

- **一条一义**：每条表达一个完整知识点，便于检索与引用。
- **必带溯源**：自动切片条目须有 `source_doc_id + chunk_index`；无来源的人工条目须标 `confidence` 与 `source_type: 人工录入`。
- **关键词 3~8 个**：覆盖同义表述，提升召回。
- **分面必填**：`domain` 与 `applicable_template` 用于精准召回。

## 4. 生命周期

- `active`：可检索；`merged`：已并入他条；`deprecated`：停用不可检索。
- 修改产生新版本，旧版保留溯源。
