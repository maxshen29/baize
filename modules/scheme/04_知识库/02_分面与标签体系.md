# 02 · 分面与标签体系

> 定义知识库检索用的「分面（Facet）」与受控标签，保证召回精准、可筛选。
> 对应设计见 `01_方案/05_模块设计_知识库.md` §4。

## 1. 分面（Facet）维度

| 分面 | 含义 | 取值示例 |
| --- | --- | --- |
| domain（领域） | 知识点业务领域 | 资质, 技术方案, 实施, 商务, 售后, 风险, 案例 |
| applicable_template（适用模板） | 该知识适配的模板类型 | 投标方案, 技术方案, 实施方案 |
| source_type（来源类型） | 原始材料性质 | 资质文件, 历史业绩, 规范标准, 网页, 人工录入 |

## 2. 受控标签（初始表，可扩展）

- **domain**：`资质` / `技术方案` / `实施` / `商务` / `售后` / `风险` / `案例` / `行业背景`
- **applicable_template**：取自 `02_模板/10_模板元数据规范.md` 的 `type` 受控表（投标方案/技术方案/实施方案/…）
- **source_type**：`资质文件` / `历史业绩` / `规范标准` / `网页` / `人工录入`

## 3. 标签治理

- 受控标签集中维护于此文件，新增需评审并同步更新模板 `source_tags` 取值范围。
- 自由标签（如项目名）不进分面，仅作关键词。
- 标签冲突时以本文件为准。

## 4. 与检索的关系

- 撰写引擎按当前模板 `type` 自动注入 `applicable_template` 过滤，提升相关性。
- 用户可在检索 UI 叠加 `domain` / `source_type` 分面。
