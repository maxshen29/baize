# 01 · 需求分析

> 变更记录：2026-09-18 初版。

## 1. 利益相关者与角色

| 角色 | 核心诉求 | 主要使用能力 |
| --- | --- | --- |
| 方案工程师 | 快速起稿、内容可用、少返工 | ①②③④ |
| 知识管理员 | 资料不丢失、知识准确、易检索 | ②③ |
| 项目经理 | 范围可控、质量可审、可交付 | ④ + 检查/导出 |
| 平台维护者 | 模板可维护、系统稳定 | ① + 配置 |

## 2. 功能需求（按能力分组）

### 2.1 能力① 可复用参考结构模板（FR-TPL）
- FR-TPL-1：创建/编辑/删除模板，含多层章节树。
- FR-TPL-2：每章节支持「写作指引、是否必填、占位符、适用标签」。
- FR-TPL-3：模板元数据（类型、场景、版本、作者、适用领域）。
- FR-TPL-4：模板列表检索与按类型筛选。
- FR-TPL-5：基于模板一键初始化「撰写任务」骨架。

### 2.2 能力② 导入并管理参考文档（FR-DOC）
- FR-DOC-1：导入 Word/PDF/Markdown/网页/图片（OCR 可选）。
- FR-DOC-2：解析为 Markdown/纯文本，保留结构（标题层级）。
- FR-DOC-3：文档元数据（来源、类型、日期、标签、密级）。
- FR-DOC-4：版本管理（同文档更新产生新版本）。
- FR-DOC-5：去重（基于 checksum/content hash）。
- FR-DOC-6：文档检索与预览、删除/归档。

### 2.3 能力③ 构建可检索知识库（FR-KB）
- FR-KB-1：从文档自动切片生成知识条目（可人工校正）。
- FR-KB-2：支持人工录入知识条目。
- FR-KB-3：关键词检索 + 语义（向量）检索。
- FR-KB-4：分面筛选（领域 / 适用模板 / 来源类型）。
- FR-KB-5：每个条目含来源溯源与置信度。
- FR-KB-6：条目编辑、合并、停用。

### 2.4 能力④ 基于知识库按需撰写（FR-WRITE）
- FR-WRITE-1：基于模板生成方案大纲（章节骨架）。
- FR-WRITE-2：按章节/整篇生成内容，注入相关知识。
- FR-WRITE-3：局部扩写 / 改写 / 续写。
- FR-WRITE-4：插入引用（溯源到知识条目）。
- FR-WRITE-5：全局事实一致性约束（公司名、资质、金额）。
- FR-WRITE-6：人工在线编辑与版本管理。
- FR-WRITE-7：导出 Word/PDF，保留引用标记。

### 2.5 通用检查（FR-CHECK，附属于④）
- 全文一致性检查、废标项/强制条款检查、查重、错别字。

## 3. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 单文档解析 < 30s（常规）；知识检索 < 1s（百万级条目内） |
| 可检索 | 关键词精准 + 语义召回，支持分面 |
| 可溯源 | 生成段落可回溯来源条目/文档 |
| 可编辑 | 任意节点可人工修改，AI 不锁死 |
| 隐私/离线 | 默认本地存储，可选不上云 |
| 可扩展 | 模板/解析器/检索器可插拔 |
| 可用性 | 非技术角色可上手，模板即引导 |

## 4. 约束与假设

- 依赖外部 LLM/嵌入服务（通过网关接入，支持 OpenAI-like 与本地 Ollama）。
- 复杂 PDF（扫描件、表格）解析质量有限，需 MinerU/OCR 兜底。
- 本期不实现多人实时协同编辑（远期）。

## 5. 优先级（MoSCoW）

- **Must**：FR-TPL-1~5、FR-DOC-1~4、FR-KB-1~5、FR-WRITE-1~6。
- **Should**：FR-DOC-5/6、FR-KB-6、FR-WRITE-7、FR-CHECK。
- **Could**：OCR、语义检索（先在关键词上叠加）、协同编辑。
- **Won't（本期）**：模型训练、实时协同、移动端。
