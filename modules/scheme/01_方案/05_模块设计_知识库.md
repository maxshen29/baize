# 05 · 模块设计 · 可检索知识库（能力③）

> 变更记录：2026-09-18 初版。对应目录 `04_知识库`。

## 1. 职责

- 把参考文档切片 + 人工录入整理为「知识条目」。
- 提供关键词 + 语义检索、分面筛选、溯源与置信度管理。

## 2. 核心流程

```
[来自能力②] 文档切片 → 生成候选知识条目(可人工校正)
[人工] 直接录入知识条目
   → 计算嵌入向量 + 关键词索引
   → 写入 04_知识库/知识条目 (+ 元数据/分面/溯源)
   → 对外提供检索 API
```

## 3. 知识条目数据结构（草图）

```yaml
knowledge_entry:
  id: KE_20260918_资质.md
  title: 公司具备ISO9001认证
  content: 公司持有ISO9001:2015质量管理体系认证，证书编号...
  source_doc_id: doc_xxx        # 溯源到参考文档
  chunk_index: 12               # 文档内切片位置
  embedding: <vector>           # 语义检索
  keywords: [ISO9001, 认证, 资质]
  facets:
    domain: 资质        # 领域
    applicable_template: [投标方案, 技术方案]   # 适用模板
    source_type: 资质文件
  confidence: 0.95      # 人工条目可标注
  status: active | merged | deprecated
  created_at: 2026-09-18
```

## 4. 检索设计

- **关键词**：标题/正文/关键词全文索引（BM25），精确匹配。
- **语义**：嵌入向量近邻检索（pgvector / Qdrant / Chroma）。
- **混合召回**：关键词 + 向量加权融合，Top-K 返回。
- **分面筛选**：按 `domain / applicable_template / source_type` 过滤。
- **溯源**：每条结果回带 `source_doc_id + chunk_index`。

## 5. 关键接口（规划）

- `POST /kb/entries` 录入；`POST /kb/entries/from-doc` 文档切片。
- `GET /kb/search?q=&facets=&k=` 混合检索。
- `PATCH /kb/entries/:id` 校正/合并/停用。

## 6. 关键设计决策

- **切片粒度 = 段落/章节**：兼顾语义完整与溯源精度（避免过长/过碎）。
- **先关键词后语义**：早期仅关键词即可用，向量为增强。
- **分面绑定模板**：`applicable_template` 让撰写引擎按当前模板精准召回。

## 7. 上下游

- 上游：能力② 文档切片、人工录入。
- 下游：能力④ 撰写引擎检索知识并引用。
