# 07 · 数据模型与存储设计

> 变更记录：2026-09-18 初版。

## 1. 实体关系概览

```
Template 1──* TemplateSection
ReferenceDocument 1──* KnowledgeEntry (切片来源)
KnowledgeEntry *──* Template (applicable_template 多对多)
WritingTask 1──1 Template
WritingTask 1──* SectionContent (对应 TemplateSection)
SectionContent *──* KnowledgeEntry (citations 多对多)
```

## 2. 核心实体字段

### 2.1 Template / TemplateSection
- Template：`id, type, name, scenario, version, author, tags[], created_at`
- TemplateSection：`id, template_id, parent_id, title, level, required, placeholders[], guidance, source_tags[], order`

### 2.2 ReferenceDocument
- `id, title, source_type, original_path, parsed_path, status, checksum, tags[], classification, version, imported_at, chunk_count`

### 2.3 KnowledgeEntry
- `id, title, content, source_doc_id, chunk_index, embedding(vec), keywords[], facets{domain, applicable_template[], source_type}, confidence, status, created_at`

### 2.4 WritingTask / SectionContent
- WritingTask：`id, template_id, title, kb_scope[], global_facts(json), status, created_at`
- SectionContent：`id, task_id, section_id, title, content, status(draft/review/done), citations[](→KnowledgeEntry.id), version, updated_at`

## 3. 存储选型

| 数据 | 选型 | 说明 |
| --- | --- | --- |
| 元数据（模板/文档/条目/任务） | SQLite（本地优先）或 Postgres | 关系清晰、易查询 |
| 向量（嵌入） | pgvector（Postgres）或 Qdrant/Chroma | 语义检索 |
| 原始文档/解析文本 | 文件系统（本地）或对象存储 | 大文件不进库 |
| 生成结果 | 文件系统（md/docx）+ 元数据行 | 便于版本与导出 |

- **本地优先**：默认 SQLite + 本地文件 + 本地向量（Chroma/Qdrant 单机）。
- **团队版**：Postgres + pgvector，集中检索服务。

## 4. 切片与嵌入策略

- 切片单位：参考文档的「章节/段落」，长度 200~800 字为宜。
- 每切片 → 一条 KnowledgeEntry，带 `source_doc_id + chunk_index` 溯源。
- 嵌入模型：可配置（OpenAI-like 或本地 bge/embedding），维度随模型。
- 关键词索引：标题/正文/keywords 建全文索引（FTS5 / Postgres FTS）。

## 5. 版本与溯源

- 模板/文档/任务均带 `version`，更新产生新版本而非覆盖。
- 生成内容 `citations` 指向知识条目，`source_doc_id` 再指向原文，形成两级溯源。
- 长任务（解析/生成）异步落盘，支持中断恢复（借鉴 OpenBidKit `piPersistentTaskStore`）。

## 6. 索引设计

- KnowledgeEntry：`(domain)`, `(applicable_template)`, `(source_type)` 分面索引；`embedding` 向量索引；`keywords` 全文索引。
- ReferenceDocument：`(checksum)` 去重；`(tags, source_type)` 检索。
- Template：`(type, tags)` 检索。
