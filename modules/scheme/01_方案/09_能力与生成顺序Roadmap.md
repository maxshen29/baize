# 09 · 能力与生成顺序 Roadmap

> 变更记录：2026-09-18 初版。明确四大能力「依次实现」的顺序、依赖与里程碑。

## 1. 生成顺序总览

平台根目录编号即体现顺序：`00_文档` → `01_方案` → `02_模板` → `03_参考文档` → `04_知识库` → `05_代码`。

四大能力落地顺序（依赖关系驱动）：

```
① 参考结构模板  ──┐
                  ├─▶ ③ 可检索知识库 ──▶ ④ 按需撰写
② 参考文档管理  ──┘        ▲
                           │
              ② 为 ③ 提供切片来源
```

- **① 模板** 与 **② 文档管理** 可并行起步（互不依赖）。
- **③ 知识库** 依赖 ②（切片来源），并用 ① 的 `source_tags` 做精准召回。
- **④ 撰写** 依赖 ①③（模板定结构、知识库供内容）。

## 2. 里程碑

### M0 · 框架与文档（本次，已完成）
- 目录框架、命名规范、总体方案与四大能力设计文档。

### M1 · 模板体系（能力①）
- 模板 CRUD、章节树、元数据规范（`02_模板/10_模板元数据规范.md`）。
- 交付：`02_模板` 示例模板（投标/技术/实施方案）。

### M2 · 知识库（能力③，数据结构先行）
- 知识条目模型、关键词检索、分面体系（`04_知识库/01_知识条目规范.md`、`02_分面与标签体系.md`）。
- 先关键词后语义。

### M3 · 文档导入（能力②）
- 解析管线、版本/去重（`03_参考文档/01_导入流程说明.md`）。
- 文档解析结果自动喂给 M2 切片。

### M4 · 撰写引擎（能力④）
- 大纲生成、逐章生成、引用、编辑、检查、导出（`05_代码`）。
- 串联 ①③。

### M5 · 检查与导出增强
- 一致性 / 废标项 / 查重 / 错别字；Word/PDF 导出保留引用。

## 3. 依赖与风险

| 依赖 | 风险 | 缓解 |
| --- | --- | --- |
| ④ 依赖 ①③ | 模板/知识质量差 → 生成差 | M1/M2 先打磨元数据与切片 |
| ③ 依赖 ② | 解析失败 → 知识空缺 | M3 解析失败可恢复 + OCR 兜底 |
| 语义检索 | 嵌入质量不稳 | 先关键词，向量为增强 |

## 4. 当前状态

- ✅ M0 完成。
- ⏸️ M1~M5 待开发，按本 Roadmap 顺序推进。
