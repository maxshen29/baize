# 03 · 模块设计 · 参考结构模板（能力①）

> 变更记录：2026-09-18 初版。对应目录 `02_模板`。

## 1. 职责

- 管理「结构模板」：只定义章节骨架与每节写作指引，不含正文。
- 提供模板检索、初始化撰写骨架、与知识库标签联动。

## 2. 核心流程

```
创建模板 → 定义章节树(标题/层级/必填/占位符/指引/标签)
   → 保存元数据(类型/场景/版本)
   → [引用] 被撰写任务初始化时拉取骨架
```

## 3. 模板数据结构（草图）

```yaml
template:
  id: tpl_xxx
  type: 投标方案 | 技术方案 | 实施方案   # 见 02_模板/10_模板元数据规范.md
  name: 通用信息化项目投标方案
  scenario: 政企信息化采购
  version: 1.0.0
  author: 知识管理员
  created_at: 2026-09-18
  tags: [信息化, 政府采购]
  sections:                     # 有序章节树
    - id: s1
      title: 项目理解
      level: 1
      required: true
      placeholders: [项目名称, 采购人]
      guidance: 说明对需求的理解，引用类似案例
      source_tags: [案例, 需求]   # 建议检索的知识标签
    - id: s2
      title: 技术方案
      level: 1
      children:
        - id: s2_1
          title: 总体架构
          level: 2
          guidance: 给出架构图(mermaid)与分层说明
```

## 4. 关键接口（规划）

- `POST /templates` 创建；`GET /templates?type=&tag=` 检索。
- `GET /templates/:id` 详情（含 sections）。
- `POST /templates/:id/clone` 复制为草稿。
- `POST /writing-tasks/init` 用模板初始化撰写骨架（见 06）。

## 5. 关键设计决策

- **结构/内容分离**：模板零正文，保证可跨项目复用。
- **每节带 guidance + source_tags**：既是写作提示，也是撰写时的知识检索提示词。
- **版本化**：模板演进不影响历史方案。

## 6. 上下游

- 上游：知识管理员维护。
- 下游：能力④ 撰写引擎依 `sections` 生成大纲与逐章内容。
- 关联：`02_模板/10_模板元数据规范.md` 定义元数据字段约束。
