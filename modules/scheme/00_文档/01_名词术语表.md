# 01 · 名词术语表

> 统一平台内用词，避免「方案/标书/模板/知识条目」等概念歧义。

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 方案 | Proposal / Scheme | 面向特定目标的正式文档，如投标方案、技术方案、实施方案。 |
| 参考结构模板 | Structure Template | 只定义「章节骨架 + 每节写作指引」的复用单元，不含正文。 |
| 模板章节 | Template Section | 模板中的一个节点，含标题、层级、是否必填、占位符、写作指引、适用标签。 |
| 参考文档 | Reference Document | 被导入管理的源材料（资质、历史方案、规范、标准、网页等）。 |
| 解析 | Parsing | 把 Word/PDF/网页等转为 Markdown/纯文本的过程。 |
| 知识条目 | Knowledge Entry | 知识库的最小可检索单元，由文档切片或人工录入得到，带标签与溯源。 |
| 分面 | Facet | 知识条目的可筛选维度，如「领域 / 适用模板 / 来源类型」。 |
| 嵌入向量 | Embedding | 文本的数值表示，用于语义检索。 |
| 按需撰写 | On-demand Authoring | 按模板章节逐一生成内容，支持选中章节、局部扩写、引用知识。 |
| 全局事实 | Global Facts | 跨章节必须保持一致的关键事实（公司名、资质编号、金额等）。 |
| 溯源 | Provenance | 生成内容所引用的知识条目/文档来源，便于审校。 |
| 废标项 | Rejection Clause | 投标中一旦不满足即废标的强制性条款（场景化检查项）。 |
| 查重 | Duplicate Check | 检查方案内部或与历史方案的重复表达。 |
| 撰写任务 | Writing Task | 一次「基于某模板生成某方案」的作业实例，含章节状态与版本。 |

## 约定

- 文档内统一使用上述中文术语；代码/接口可用英文。
- 「模板」特指**结构模板**（无正文）；「知识条目」特指知识库单元；二者不混用。
