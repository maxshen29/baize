# 00 · 代码库说明

> 本目录（`05_代码`）承载「能力④ 基于知识库按需撰写」的引擎与平台实现。
> **当前状态：开发中（M1~M4 代码骨架已落地，后端可运行、前端可构建）**。技术栈为 **Vue3 + FastAPI + PostgreSQL(pgvector)**，数据库部署在远程服务器（建表由 `../db/schema.sql` 在服务器执行）。

## 1. 定位

- 实现 `01_方案/06_模块设计_按需撰写.md` 的撰写引擎与检查/导出。
- 复用 `02_模板`（结构）、`04_知识库`（检索，见 `11_本地知识库建设方案.md`）。

## 2. 仓库骨架（monorepo，开发期创建）

```
方案系统/
├── web/                        # Vue3 + Vite + TS 前端
│   └── src/
│       ├── api/                # axios 封装（调用 FastAPI）
│       ├── views/              # 模板/文档/知识库/撰写/导出 页面
│       ├── components/         # 章节树、检索结果、引用面板
│       └── stores/             # Pinia（writing task / kb scope）

│   └── app/

│       ├── routers/            # template/document/knowledge/writing/check/export
│       ├── services/           # Template/Document/Knowledge/Writing/Check/Export
│       ├── models/             # SQLModel 表（见 07_数据模型）
│       ├── schemas/            # Pydantic 入出参
│       └── infra/
│           ├── storage/        # 文件 + Postgres 元数据
│           ├── vector/         # pgvector 读写（见 11_本地知识库建设方案）
│           ├── parser/         # doc→md（python-docx/pypdf/MinerU）

```

## 3. 技术栈（确定）

- 前端：Vue3 + Vite + TS + Pinia + Vue Router + Element Plus/Naive UI。
- 后端：Python 3.11+ FastAPI + Pydantic v2 + SQLModel。
- 数据库：PostgreSQL 16 + pgvector（元数据 + 向量一体）。
- 嵌入：本地 Ollama `bge-m3`；LLM：OpenAI-like / Ollama 本地。
- 编排：LangGraph（大纲→逐章→检查）。
- 导出：python-docx / pandoc。

详见 `01_方案/08_技术选型与工程规范.md` 与 `10_实现路径分析.md`。
