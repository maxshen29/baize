# 01 · 导入流程说明

> 定义「能力② 导入并管理参考文档」的标准流程。对应设计见 `01_方案/04_模块设计_参考文档管理.md`。

## 1. 支持来源

- 文件：Word(.docx)、PDF、Markdown、纯文本、图片（OCR 可选）。
- 链接：网页（抓取正文转 md）。

## 2. 标准步骤

```
1) 选择来源（文件/链接）
2) 选择解析方式：本地（mammoth/pandoc） | MinerU（复杂PDF） | OCR（扫描件）
3) 系统解析为 Markdown，保留标题层级
4) 补全元数据：标题/来源类型/日期/标签/密级
5) 计算 checksum 去重（与既有文档比对）
6) 入库：原文存 导入物/，解析文本存 导入物/<名>.md
7) 触发知识库切片（见 04_知识库）
```

## 3. 解析策略

| 类型 | 解析器 | 备注 |
| --- | --- | --- |
| docx | mammoth | 保标题层级 |
| pdf(文本) | pandoc / pdfplumber | 常规 |
| pdf(扫描) | MinerU / OCR | 保版面表格 |
| webpage | Readability 类 | 抓正文 |
| image | OCR | 可选 |

## 4. 质量与恢复

- 解析失败标记 `failed`，保留原文件，支持重试，不污染知识库。
- 长解析任务异步落盘，可中断恢复（借鉴 OpenBidKit 后台任务恢复）。

## 5. 版本管理

- 同文档更新 → 新版本（`version+1`），旧版本保留供溯源。
